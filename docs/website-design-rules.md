## 已確定的使用方向

使用者已否決 2026-10-26 五入口方案。日常頁面由當下要寫的內容、未完成文字、當日經文與近期可接續的閱讀構成。功能仍可找到，主畫面的比例與次序依使用行為決定，避免要求使用者先理解功能分類才開始。

短記可從一行文字開始，日期可作暫用識別；標題、分類、摘要與成冊設定可以稍後補齊。編輯器保留長篇需要的結構與工具，但初次起筆不顯示整張設定表。已有文字時以內容及保存狀態為主，長文、短記、圖片與來源引用依其內容採不同版面。

接續使用須能辨認上次寫到哪裡、最後可靠的保存位置及可閱讀的近期內容。儀表板數字、成就、連續天數與完成率不佔據主要入口。日期麥琴沿用既有曆日規則，不增添個人讀經完成追蹤。

搜尋呈現命中字句及所屬內容，使用者從結果判斷能否找到所需段落。經文、個人心得、引用來源與相關紀錄的關係要看得懂；新增連結或來源註記時須包含建立、查看、失效與移除的完整流程。未實作的能力列為後續建議，不先製作會誤導成功的入口。

## 組件及裝飾限制

- 不以等寬、等高、白底、圓角、淡陰影卡片反覆承載所有內容；首頁、編輯器與說明頁亦同。
- 漸層、色彩、幾何與動態需共同服務完整構圖；依使用者對 Goons 的明確偏好檢視實際效果。避免以淡色漸層、大型裝飾序號、任意彩色邊條、無意義圖示底座、裝飾英文及統一滑過浮起充作整頁設計。
- 不重建固定五個功能區塊、五張入口卡或相同入口的其他排列。保留功能可達性時，依當前操作使用適合的選單、工具或上下文入口。
- 留白須反映內容關係。檢查相鄰容器的 padding、margin、空標題與預留高度，避免重複間距、右側大片空白或內容黏邊。
- 按鈕、表單與選單採一致尺寸、邊界、字級及狀態；同一操作的名稱與位置跨頁一致。高風險操作與日常操作有清楚差別，避免與保存鍵緊鄰到容易誤按。
- 圖示須有可辨認的含義，必要時附可讀名稱；圖示按鈕有可及名稱。頁面內容不靠圖示與色彩單獨說明。
- 不把版本、實作方式、資料表、除錯文字及工程狀態放進使用者主要流程。帳戶或說明頁可放必要的版本資訊。

## 字體與中文閱讀

- 使用繁體中文完整字形，避免同段因字庫缺字混雜字型。字型數量與載入成本由閱讀品質決定，不把三策指定品牌字型直接套入本站。
- 主要文字在手機至少 16px；註記須能閱讀且有充分對比。行長、行距與段距以連續讀完長文和經文為準，分別檢查手機與桌機。
- 正文靠左、依欄寬自然換行。段落依思想分隔；保留使用者自行輸入且具內容意義的換行，不把系統範文排成社群短句。
- 不以 `text-wrap: balance/pretty`、段尾 `nowrap`、強制換行、窄固定欄寬或左右切齊改造正文。標題可在不破壞語意的前提使用平衡換行。
- 標題保留完整詞組，不讓最後一行僅剩一個中文字及標點。優先調整可用欄寬、字級層級、字距與斷點；禁止截字、刪文、整段不換行或縮成難讀小字。
- 題名在首頁、近期內容、列表、搜尋、編輯器、成冊、書房、閱讀器與匯出一致。修改名稱須檢查全部入口，長題名和多行題名一併驗證。
- 內容不可因卡片高度而藏掉唯一辨識資訊。需要摘要截斷時保留全文入口，讀取狀態與可點範圍可辨識。

## 可及性及互動

- 正常字級文字對比至少 4.5:1，包含按鈕內文、placeholder、選項、停用說明與訊息。深底／淺字、淺底／深字在所有狀態分別檢查。
- 一般觸控目標至少 44×44px，保留可辨認的焦點框；鍵盤可到達主要控制項。原生 checkbox、radio 與表單語意優先，避免放大到壓迫文字。
- 載入中、空資料、首次使用、離線、登入過期、保存失敗、衝突、成功及停用狀態逐項測試。錯誤訊息緊鄰受影響操作，保留必要的資料保護提示。
- 模態視窗要有可發現的入口、標題、關閉鍵、Escape 與正確焦點順序；開啟時背景停止操作及捲動，關閉後焦點回到原入口。長內容可在視窗內捲動，手機鍵盤不遮住動作鍵。
- 黏性頁首、錨點與閱讀進度依實際頁首高度計算，避免寫死位移。關閉設定、目錄與詳情後保留閱讀位置。
- 動態效果只表達展開、保存或頁面關係，尊重 `prefers-reduced-motion`；背景分頁暫停無需持續的動態。不得套入三策輪播或跑動經文作為固定需求。

## 圖片與經文內容

圖片須與內容有實際關係，由使用者內容或已授權素材決定。短記、禱告及純文字札記不被要求附圖。避免以窗光、咖啡、樹葉與同類通用擺設反覆填空。

新增影像查看原尺寸，檢查眼睛、手指、物件幾何、裁切、文字、重複紋理與場景可信度；人物姿勢及場景需符合內容，不用不自然托腮或昏睡神情代表靈修。合成影像不得聲稱真實人物或實績照片。手機與桌機各自確認主體與必要內容未被裁掉。

經文按原文、出處、段落及上下文保留；應用文字與引文分開。不得為行銷、字數或版面將聖經應許寫成個人結果保證。既有聖經校對的未決項目須逐項由適當來源確認，不在排版任務批次改字。

## 2026-11-13 後續退回與必查項目

使用者接續退回過量空白、任意大小字、文字位置分散、缺少可感受的互動，以及米色／灰綠／磚紅配色。這些項目與操作箭頭均未獲認可；先前候選與本次重排都不得當成已接受設計。

- 禁止在按鈕、連結或段尾加入裝飾箭頭，包含文字字元、SVG、圖片與 CSS 產生的符號。章節排序使用「上移」「下移」文字。`verify:design` 分別掃描來源與建置結果；人工檢查補足圖像及執行後的呈現。
- 每段具有明確內容範圍：區段標題、資料、操作須看得出歸屬。標題與內容共用左緣；日期及來源緊鄰所屬內容；避免小標在左、日期在右、內文另起位置的散置方式。
- 字級按用途固定。一般區段標題使用同一層級；經文章名、札記題名及正文各用一致尺寸。圖片、題名或章名放大須由完整構圖及內容需要支持。
- 取消為捲動動畫新增的空段、全視窗強制高度，以及相鄰區塊累加的上下間距。長文編輯區保留輸入空間，工具與保存動作可見；桌機按鈕依文字寬度排列，避免整欄長條。
- 舊配色整組停用；本機新候選使用白底、墨黑字與深藍操作色，仍待使用者檢視。手機、編輯器、視窗與舊共用元件均查驗實際背景和對比。
- 動態在開啟、關閉、頁面切換及自然捲動中驗證，記錄觸發、可見變化、結束時間和中斷行為。輸入文字時取消書寫頁的移動；減少動態偏好下停止動畫。不得以存在動畫程式碼宣告互動已驗收。
